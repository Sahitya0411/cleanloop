# Demo video script (3 minutes)

Judges see only the recorded video, so it has to show **what CleanLoop does, who it is for, and where AWS fits**. Record the phone screens with a real phone (or Chrome DevTools device mode at Pixel 7 size) and the officer screens on a laptop. Use the deployed app so Claude, SES and SNS are real.

**Before recording**

- Deploy, then click the SES verification links so the officer email arrives on camera.
- On a resident account, turn on email lane alerts and confirm the subscription.
- Have three real objects ready (a plastic bottle, a banana peel, an old charger) and a photo of an overflowing bin. A street bin works; so does a printed photo.
- Officer → Routes → **Reset today (demo)** so the route starts at 0 stops.
- Keep the AWS console open on: the CloudWatch dashboard, the DynamoDB table, and the Lambda list.

**Tips**

- Keep each cut under 10 seconds and narrate over the action; don't wait for screens to load on camera.
- Show the low-confidence fallback with a blurry photo if you have a spare 5 seconds; it shows careful design.
- Say "estimate" when you show diesel and CO₂.
